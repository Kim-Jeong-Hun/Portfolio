# Portfolio
포트폴리오용 페이지

## 컨텐츠
### header
- 네비게이션 (스크롤해도 따라다니는 네비게이션 바)
(Intersection Observer API를 통해 
섹션 이동시 네비게이션 underline 변경 적용)
- 헤드라인
(배경이미지 + 한 줄 소개)

### main
#### section 1
- 프로필(학력, 자격증, 경력)
(Intersection Observer API를 통해 
DOM요소의 30%가 화면에 표시될 시, 
프로필 헤드라인과 프로필 카드들이 fade-in)
#### section 2
- 기술 스택
#### section 3
- 프로젝트 (진행 중 / 완료)
#### section 4
##### article
- GitHub 잔디
##### aside
- 현재 관심사

#### footer
- 꼬리말(저작권/다른 페이지)


### 주의사항
- 나중에 프로필 섹션의 각 박스에 
사이드로 확장되는 애니메이션 추가 예정

- 기술 스택
표를 만들어 해당하는 태그 클릭시 해당 태그 밝게 표시

ex) 중급 & 프론트엔드 선택 = React 표시되게

    디자인 | 프론트엔드 | 라이브러리 | 환경 및 배포
초급 | 피그마 | JS | React | 스택4 ...
중급 | 스택11 | ...
고급 | 스택21 | ...
